# Lindvimera

ObsidianのSourceモードとLive Previewで、日本語の単語・文操作、MarkdownのVim編集、ネイティブテーブルのセル編集を提供するプラグインです。対象環境はWindows・Obsidian **1.15.0以降**です。

本文の編集にはVimを使い、ノート・タブ・サイドバーの操作にはObsidianを使います。Normal／Visualでは対応するVim操作を優先し、InsertではObsidianの通常入力・補完・貼り付けを使います。日本語入力とIMEはObsidianへ渡し、Vimコマンドと脱出キー列は英数の直接入力で使用します。

## インストール

Git、Node.js 24系（24.15.0以上）、pnpm **12.10.1**を用意し、リポジトリのルートで実行します。初回ビルドの辞書取得にはネットワークが必要です。

```powershell
git submodule update --init --recursive
pnpm install --frozen-lockfile
pnpm check
```

1. 利用するエンジンを決めます。既定の同梱エンジンはObsidianのVimキー設定をオフにして使います。
2. `dist/`の`main.js`・`manifest.json`・`styles.css`をVaultの`.obsidian/plugins/lindvimera/`へコピーします。WASM・辞書と必要なライセンス・改変ソースは`main.js`にも内包しています。公開済みバージョンはGitHub Releasesの同じ3ファイル、または`lindvimera-<version>.zip`から導入できます。
3. Obsidianを再読み込みし、コミュニティプラグインからLindvimeraを有効にします。

まず独立したテストVaultで操作を確認してください。外部Neovim、Lua、vimrc、追加のネイティブモジュールは不要です。モバイルは対象外です。

## エンジンの選択

設定で「同梱エンジン」または「組み込みVim（実験的）」を選び、プラグインを再読み込みすると適用されます。同梱エンジンは既定の独立したVim実装、組み込みVimはObsidian 1.15のネイティブVim実装を使います。明示した選択に合わせ、起動時にObsidianのVimキー設定も同期します。旧設定に選択がない場合は、現在のホスト設定を維持します。

エンジンは同時に入力を処理しません。外部からホストのVimキー設定が変更されて競合したときは、その場でLindvimeraの入力を停止します。選択したエンジンが使えない場合も自動で別エンジンに切り替えません。保存した設定とキー割り当ては共有しますが、レジスタ・マーク・検索・マクロ・モード・Undoの一時状態は移しません。

以下の詳細な操作説明は同梱エンジンの契約です。実験的な組み込みVimでは標準操作をホストへ委譲し、日本語・Markdown拡張をそのネイティブエディタへ追加します。ホスト固有の操作や表セルごとの状態はホストの仕様に従います。互換性とエンジンごとの動作は[1.15互換性一覧](docs/obsidian-115-compatibility.md)を参照してください。

## 入力の優先順位と対応操作

同じキーでも、現在のUIと編集モードで役割が決まります。一回の入力で候補の取消とモード解除を同時に実行しません。

| 状態                                    | 優先する操作                                                     |
| --------------------------------------- | ---------------------------------------------------------------- |
| IME変換中                               | IMEの変換・確定・取消                                            |
| モーダル・検索欄などの専用入力UI        | そのUIの入力                                                     |
| 補完・リンク候補の表示中                | 候補が使う矢印・Enter・Tab・Esc                                  |
| Normal／Visual／operator待ち            | 対応するVim編集操作とモード別キー割り当て                        |
| Insert／Replace                         | Obsidianの通常入力と、Vimの脱出・明示的な割り当て・Replaceの置換 |
| Vimに割り当てのないアプリショートカット | 登録済みのObsidianコマンド                                       |

例えばNormal／Visualの`Ctrl-f/b/d/u`はVimの画面移動、InsertではObsidian側の動作です。Normal／Visualの`Ctrl-c`は取消、`Ctrl-v`は矩形選択です。Insertのコピー・貼り付けはObsidianに従います。

不成立のVimキー列は待機を解除して終了し、後続文字で別のホスト編集を起こしません。アプリショートカットを実行すると、途中のoperator・カウント・レジスタ指定は解除されます。Normalの未対応文字は本文に挿入されません。

対応範囲は次の編集機能です。上流Vimの全機能は継承しません。

| 分類             | 対応操作                                                                                                                     |
| ---------------- | ---------------------------------------------------------------------------------------------------------------------------- |
| モード・編集     | `i/I/a/A/o/O`、`r/R`、`d/c/y`と行操作、`x/X/D/C/s/S/Y`、`p/P/J/gJ`、`>/< /=`、`~`、`gu/gU/g~/g?`、`u/Ctrl-r`                 |
| 移動             | `h/j/k/l`、`w/b/e/ge/W/B/E/gE`、`0/^/$`、`+/-/_`、`gg/G`、`f/F/t/T`、`;`、`,`、`%`、`{}/()`                                  |
| 画面移動         | `gj/gk`、`Ctrl-f/b/d/u`、`H/M/L`、`zz/zt/zb`                                                                                 |
| 折り畳み         | `za/zo/zc`、`zA/zO/zC`、`zR/zM`（本文専用）                                                                                  |
| 選択・検索       | `v/V/Ctrl-v`、`gv`、選択端移動、単語・文・段落・引用符・括弧のテキストオブジェクト、`/ ? n N * # g* g# gn gN`、Visualの`u/U` |
| 記録・組み合わせ | カウント、operator＋motion／object、名前付きレジスタ、`.`、`q/@`、モード別キー割り当て                                       |
| ノート内の履歴   | `m[a-z]`、`'[a-z]`、バッククォート＋`[a-z]`、`Ctrl-o/Ctrl-i`                                                                 |
| Ex編集・検索     | `:s[ubstitute]`、`:d[elete]`、`:y[ank]`、`:pu[t]`、`:j[oin]`、`:sort`、`:noh[lsearch]`、行番号、`@:`                         |
| 独自機能         | 日本語単語操作、Markdown移動・オブジェクト、`gf`、Surround、テーブル連携                                                     |

矢印・Home／End・PageUp／Downは対応モーションの別名です。NormalのBackspace・Delete・Enterは、前の文字への移動・文字削除・次行の先頭への移動です。この一覧に属さない上流操作は対象外です。

数値の増減、HTMLタグのテキストオブジェクト、`gq`などの整形操作には対応していません。

モード表示は`NORMAL`・`INSERT`・`REPLACE`・Visual各種を区別します。未完のキー列とマクロ記録状態も表示します。

通常の`j/k`は折り返しによらず原文の物理行を移動し、`gj/gk`は画面上の表示行を移動します。Live Previewの本文では、折り畳まれた`<ins>`などのインラインHTMLやMarkdown装飾（`**`/`==`/`~~`/`` ` ``/`[[...|...]]`/`[text](url)`/`$math$`）を横移動（`h/l`/`<Left>/<Right>`・`w/b/e/ge`・`W/B/E/gE`・`^`）、`j/k`・`gj/gk`、および`.cm-html-embed`のクリックでスキップし、見えている本文の列を保ちます。展開された後はタグ内を1文字ずつ編集でき（前後の空タグへは行端から進入可）、`operatorPending`・矩形選択`Ctrl-v`・Sourceモード・ネイティブテーブルセルでは原文の列を使います。

## 単語・文・段落操作と日本語

上記の対応範囲で、カウント、名前付きレジスタ、`.`による繰り返し、`q`／`@`によるマクロを利用できます。

| 操作                                | 動作                                             |
| ----------------------------------- | ------------------------------------------------ |
| `w` / `b`                           | 次／前の単語の先頭へ移動                         |
| `e` / `ge`                          | 次／前の単語の末尾へ移動                         |
| `iw` / `aw`                         | 単語の内側／周囲の空白を含むテキストオブジェクト |
| `W` / `B` / `E` / `gE`、`iW` / `aW` | 空白区切りのWORD操作                             |
| `*` / `#`                           | Vimの単語検索                                    |

日本語を含む非空白区間にはLindera WASM 6.2.0と同版IPADICを適用します。例えば「今日は良い天気です。」は「今日／は／良い／天気／です／。」です。`dw`、`ciw`、`v2e`にも同じ境界を使い、`2d2w`ではoperatorとmotionのカウントを積算します。

分割モードは、辞書にある複合語を保持する`normal`と、さらに細かく分割する`decompose`から選べます。例えば「関西国際空港」は`normal`で保持し、`decompose`では「関西／国際／空港」に分割します。変更は進行中のコマンド・マクロ記録や再生が終わってから本文とセルへ反映し、選択範囲・レジスタ・Undo履歴を保持します。日本語の単語操作をオフにしても保存したモードは残ります。

ASCII英数字と`_`の連続区間は保持します。句読点・括弧・URLの記号は文字部分から分離し、連続する記号を一つにまとめます。`w`は行末の「。」に止まってから次行へ進みます。絵文字や結合文字の途中には止まりません。見出し、コード、URL、frontmatter、表にも同じ規則を適用し、原文の正規化や不可視文字の挿入は行いません。

`iw/aw/iW/aW`のカウント・空白・改行・Visual反復の規則は、日本語設定のオン・オフで変わりません。空行上の`diw`は何も変更しません。WASMと辞書は同梱し、オフラインで読み込んで全エディタで共有します。読込中や失敗時にはBudouXを使い、失敗は一度通知します。

Insert中に矢印キーやマウスで実際に位置を移すと、次の編集からUndoを分けます。移動しない`ciw`と入力は一つのUndoです。IME、脱出キー候補の表示、セル再生成による内部更新では分けません。

`(`/`)`は前／次の文、`is/as`は文の内側／周囲の空白を含む範囲です。日本語設定が有効なときは「。！？」でも区切り、連続する文末記号と直後の閉じ括弧を文に含めます。「今日は晴れです。明日は雨です。」の先頭で`)`を押すと「明」へ移動し、`vis`では最初の文だけを選択します。設定が無効なら半角の`.!?`と後続の空白・行末を使う標準規則です。書記素の途中には止まりません。

`{`/`}`は空行を境界に段落を移動します。`ip/ap`では空白だけの行も区切りとなり、行単位で段落を選びます。`dap`、`gUip`、`yis`などの組み合わせも本文・セルで使えます。

`gu/gU/g~`は対象範囲を小文字／大文字／大小反転へ変換し、`guu/gUU/g~~`は現在行に適用します。`g?`はASCII英字をROT13変換し、`g??`は現在行に適用します。`gJ`は空白を追加せず行を結合します。`g*/g#`は単語の部分一致検索、`gn/gN`は次／前の検索結果を選択します。`cgn`で検索結果を変更し、`.`で次の一致を同じように変更できます。

## ノート内のマークと移動履歴

Normalの`ma`で位置を記録し、バッククォート＋`a`で正確な位置、`'a`でその行の最初の非空白文字へ戻ります。`a`〜`z`を使用でき、本文とテーブルセルをまたいで復帰します。位置は編集やセル再生成に追従します。

検索、`gg/G`、見出し・リスト移動などのジャンプは最大100件まで記録し、`Ctrl-o`で戻り、`Ctrl-i`で進みます。`3Ctrl-o`のようなカウントにも対応します。同じノートを別ペインで開いても履歴は混ざりません。

画面外のテーブルは表示とセルの取得を待ってから復帰し、マッピング・マクロは復帰後に続行します。削除済みなど復元できない位置では元の位置と履歴を保って通知し、後続の再生を中止します。待機中のEscで取消できます。

ノート切り替え、エディタ破棄、プラグイン無効化で記録を破棄します。ノート間移動、永続保存、大文字マーク、Visual／operatorからのマーク移動には対応しません。セル移動のTabは引き続き使用できます。

## Exによる編集・検索

`:`でコマンドを入力します。範囲は行番号、現在行の`.`、最終行の`$`、全体の`%`、Visual範囲、ローカルマーク、`/検索語/`・`?検索語?`、`+/-`の相対位置、`,`による開始・終了に対応します。対象は現在の本文またはセルだけです。セル内の`%`はそのセル全体を意味し、別のセル・本文にあるマークは範囲に使えません。

| 例                        | 動作                                              |
| ------------------------- | ------------------------------------------------- |
| `:%s/old/new/g`           | 全行の一致を置換                                  |
| `:'a,'bs/(word)/[$1]/gc`  | マーク間を確認しながら置換                        |
| `:2,4delete a` / `:put a` | 2〜4行をレジスタaへ削除／現在行の後へ行として挿入 |
| `:1,$yank b`              | 全行をレジスタbへコピー                           |
| `:2,4join`                | 2〜4行を空白で結合                                |
| `:%sort! iu`              | 大小文字を無視し、重複を除いて逆順に並べ替え      |
| `:noh` / `:12`            | 検索ハイライトを消去／12行目へ移動                |

置換の正規表現は既定でJavaScript形式です。`:set nopcre`で同梱Vimのパターン形式へ切り替え、`:set pcre`で戻せます。置換文字列の`$1`〜`$99`・`$&`・`$$`はどちらでも同じ意味です。検索範囲は現在位置から前後に検索し、本文またはセル内を折り返します。例えば`:/foo/,/bar/delete`は一致する行の間を削除します。`g`は各行の全一致、`c`は確認、`i`は大小文字を無視、`I`は区別します。置換文字列は`\n`／`\r`による改行、`\t`、区切り文字のエスケープも使えます。未一致のグループは空文字となり、空の置換文字列は削除になります。空パターンは直前の検索、引数なしの`:s`は直前の置換を再利用します。絵文字・結合文字を壊さないため、書記素の途中だけに一致する結果は置換しません。

確認では`y`で置換、`n`でスキップ、`a`で残りすべて、`q`で終了、`l`で一件置換して終了します。Esc・Ctrl-[・Ctrl-cでも終了し、確定済みの置換は残ります。一回のEx編集は確認を挟んでも親ノートの一回のUndoで戻せます。マッピング・マクロは確認中に待機し、終了後に続行します。`@:`は直前のExを再実行します。

`:sort`は通常の文字列順、`!`の逆順、`i`の大小文字無視、`u`の重複除去、`n`の数値順に対応します。`:put`は文字単位のレジスタも行として挿入します。マッピングではEnterを`<CR>`と書きます。`:global/:normal`、コマンド連結、未対応フラグ、`pcre/nopcre`以外の`:set`、`:map`、ファイル・タブ操作は拒否します。

## 挿入モードからの脱出

既定の脱出操作は`Esc`または`Ctrl-[`です。候補表示がなければ一回でNormalへ戻ります。候補表示中は候補だけを閉じ、次のEscでNormalへ戻ります。IME変換中は変換の取消に使い、モードを同時に変えません。Visualでは選択を解除し、未完のコマンドがあれば待機を解除します。NormalのEscでは本文やテーブルセルから退出しません。

任意の脱出キー列は初期状態で無効なので、`jj`も通常の入力です。有効にするには設定へ`["jj"]`などのJSON配列を指定します。

- キー列は2文字以上の印字可能なASCII文字です。`jj`と`jk`のような共通接頭辞は使えますが、`jj`と`jjj`のような完全な接頭辞の重複は使えません。
- 候補文字は入力位置に即座に表示します。キー列が成立すると消え、不一致や時間切れでは一度だけ本文へ確定します。判定時間の既定値は200msです。
- `jj`を脱出キー列に設定した場合、`iabcjj`で本文と挿入記録に残る文字は`abc`です。脱出キー列はマクロや`.`の挿入記録へ入りません。設定を変更しても記録済みマクロは記録時の編集とモード遷移を再生します。
- 候補が保留されている途中でEscを押すと、保留文字を一度だけ本文に確定してからNormalへ戻ります。
- 長押し、貼り付け、`.`やマクロの再生、IME変換中には脱出判定を行いません。IMEは通常の方法で確定してから、`Esc`または英数入力の脱出キー列を使ってください。

## Markdown操作

### 行の追加と本文先頭

既定で有効な「Markdownに合わせた行追加・行頭操作」は、SourceとLive Previewの本文に適用します。

| 操作        | 動作                                                                                                  |
| ----------- | ----------------------------------------------------------------------------------------------------- |
| Normalの`o` | 現在行の末尾でObsidianのEnterを実行し、ホストのSmart Lists設定に従って行を追加                        |
| Normalの`O` | 現在の物理行の直上へ行を追加し、字下げ・引用・リストの接頭辞を継続して挿入                            |
| `^`         | 引用・リスト・タスク・ATX見出しの接頭辞を飛ばして本文の先頭へ移動。Normal・Visual・operator待ちで共通 |
| Normalの`I` | `^`と同じ本文先頭から挿入                                                                             |

`o`はSmart Listsのオン・オフ、子項目、折り畳み、空の項目からの退出をObsidianに委ねます。空のリスト項目で記号を残すとは限りません。InsertのEnterも同じホスト設定に従います。`O`は従来どおり物理行の直上へ接頭辞を引き継ぎ、タスクは未完了に戻します。

番号付きリストの採番と後続項目の調整はObsidianに委ねます。`O`では現在と同じ番号の接頭辞を挿入し、その変更に対するホストの採番処理を使います。プラグイン側でリスト全体を二重に振り直しません。

見出しで行を追加しても`#`は複製しません。`> ## 見出し`の`o`なら引用の`> `だけを継続します。本文が空の行で`^`を押しても移動せず、`I`では接頭辞の直後から入力できます。

`O/^/I`のMarkdown拡張はコード・frontmatter・表の原文・ネイティブセルには適用しません。設定をオフにするとこれらは標準Vimの動作へ戻ります。同梱エンジンでは`o`の追加処理もオフになりますが、組み込みモードの`o`と両モードのInsert Enterはホストへ委ねます。Visualの`I`による挿入と`o/O`による選択端の切り替えは設定の対象外です。`J`と段落操作は従来の動作を維持します。Smart Listsが有効な本文では、リストの字下げ・字下げ解除をホストへ渡します。Live Previewの`j/k`・`gj/gk`・横移動・クリックは、この設定と独立して本文と表示位置を維持し、両エンジン（同梱・組み込み）で同じ挙動を提供します。Source、行単位operator、`operatorPending`、矩形選択、ネイティブテーブルセルでは原文の列を使います。

カウント、`.`、マクロ、ユーザー割り当てと組み合わせられます。番号の変更と続けて入力した文字は、一回のUndoで戻せます。ユーザー割り当ては引き続き優先されます。

### 移動・テキストオブジェクト

| 操作                                      | 対象                                                 |
| ----------------------------------------- | ---------------------------------------------------- |
| `]h` / `[h`                               | 次／前の見出し                                       |
| `]l` / `[l`                               | 同じインデントの次／前のリスト項目                   |
| `gf`                                      | カーソル位置の内部リンクを開く                       |
| `i*` / `a*`、`i_` / `a_`                  | 強調の内容／区切りを含む範囲                         |
| <code>i&#96;</code> / <code>a&#96;</code> | インラインコードの内容／バッククォート列を含む範囲   |
| `il` / `al`                               | リンクの内部／リンク全体                             |
| `iC` / `aC`                               | フェンス付きコードブロックの本文／フェンスを含む範囲 |
| `ih` / `ah`                               | 現在の節の本文／見出しを含む節全体（本文専用）       |
| `iL` / `aL`                               | リスト項目の内容／接頭辞を含む項目全体（本文専用）   |

`2]h`、`di*`、`yil`、`viC`など、カウント・operator・Visual選択と組み合わせられます。リスト項目は番号やチェックボックスを含む接頭辞の長さを扱います。`il`はラベル上ではラベル、URL上ではURLを対象にします。

`ah`は現在位置を含む最も内側の節を選び、次の同じ深さか、より浅い見出しの直前まで、子見出しと本文、末尾の空行を含めます。`ih`はその節自身の見出しと本文の前後の空行を除きます。ATX形式（`#`〜`######`）と下線形式の見出しに対応し、コードやfrontmatter、引用・リスト内の見出しは節の区切りにしません。

`aL`は現在のリスト項目を、継続行・子項目・末尾の空行とともに選びます。`iL`は先頭の番号・箇条書き記号・チェックボックスと、末尾の空行・改行を除きます。子項目の記号やインデントは残します。番号付き・箇条書き・タスクリストに対応し、引用内のリストは対象外です。小文字の`il/al`は引き続きリンク操作です。

例えば`yah`で節全体をコピー、`dah`で削除、`cih`で見出しを残して本文を変更できます。`2ah`／`2aL`は親の節／項目、`3ah`／`3aL`はさらに外側を選び、`2d2ah`は積算した4階層目を対象にします。必要な親や内容がない場合は何も変更せず、`c`でもInsertへ入りません。`ih/ah/aL`は行単位、`iL`は文字単位の選択・レジスタになります。

これら4操作はSourceとLive Previewの本文で使えます。ネイティブテーブルのセルから親ノートの節を操作することはできません。本文で選んだ節に表が含まれる場合は、そのMarkdown原文も範囲に含みます。

`gf`はwikiリンクとMarkdownの内部リンクを現在のペインで開き、解決をObsidianへ渡します。見出し・ブロックへのリンクにも対応します。引用符のテキストオブジェクトはVimの規則を使います。追加のleaderキーは設けません。

| Surroundの操作例    | 結果                            |
| ------------------- | ------------------------------- |
| `ysiw)` / `ysiw(`   | 単語を`(...)` / `( ... )`で囲む |
| `yss'`              | 現在行の内容を単引用符で囲む    |
| `ds'` / `cs')`      | 単引用符の削除／括弧への変更    |
| Visual選択後に`gS)` | 選択範囲を括弧で囲む            |
| `ysiw*`             | 単語を`*...*`で囲む             |

括弧、引用符、バッククォート、Markdownの区切り文字を指定できます。開き括弧は内側に空白を追加し、閉じ括弧は追加しません。追加操作のカウントは対象範囲、削除・変更のカウントは囲みの深さに適用します。Markdownの区切り列は一つの囲みとして扱います。Normal／Visualモードの`S`はVimの行変更操作です。

## 折り畳み

SourceとLive Previewの本文で、Obsidianが提供する折り畳み範囲を操作します。見出し・リスト・コードブロックなど、実際に折り畳める範囲はObsidianに従います。

| 操作        | 動作                                 | モード         |
| ----------- | ------------------------------------ | -------------- |
| `zo` / `zc` | 一段を展開／折り畳む                 | Normal・Visual |
| `za`        | 一段の開閉を切り替える               | Normal         |
| `zO` / `zC` | 入れ子をまとめて展開／折り畳む       | Normal・Visual |
| `zA`        | 入れ子の開閉をまとめて切り替える     | Normal         |
| `zR` / `zM` | 現在のペインで全展開／すべて折り畳む | Normal         |

Normalの`2zo`／`2zc`／`2za`は階層数を指定します。大文字の再帰操作と全体操作ではカウントを使いません。Visualでは選択した行に適用し、Normalへ戻ります。対象がない位置やネイティブテーブルのセルでは何も変更しません。

折り畳みは本文・レジスタ・Undo履歴を変更せず、`.`の編集対象にもなりません。キー割り当てやマクロには使用できます。解析待ちが必要な場合は完了後に続く操作を再開し、Escやノート切り替えで中止します。設定の「Vimキーで折り畳みを操作」で無効にできます。

## Live Previewのテーブル

Obsidianのネイティブテーブルを使い、各セルを小さなVimエディタとして編集します。モード・レジスタ・記録とUndo履歴は親ノートで共有します。

| 操作                              | 動作                                                 |
| --------------------------------- | ---------------------------------------------------- |
| `h` / `j` / `k` / `l`、単語移動   | 現在セル内を移動し、セルの端で止まる                 |
| `0` / `^` / `$`、`gg` / `G`       | セル内の行頭・行末、セル内文書の先頭・末尾へ移動     |
| `/` / `?`、`n` / `N`、Visual選択  | 現在セル内で検索・選択                               |
| `dd` / `cc`、`o` / `O`、`p` / `P` | セル内の行削除・変更、改行挿入、貼り付け             |
| Normalの`Tab` / `Shift-Tab`       | 次／前のセルへ移動し、表の先頭・末尾で止まる         |
| Normalの`[t` / `]t`               | 表の直前／直後の本文へ移動し、移動先がなければ止まる |
| Insertの`Tab` / `Enter`           | Obsidianのネイティブテーブル操作                     |
| `Esc`                             | 現在セルでNormalモードへ戻る                         |
| `u` / `Ctrl-r`                    | 親ノートのUndo／Redo                                 |

通常の移動・検索・選択・Surroundはセル内で完結します。`Esc`では表から出ません。貼り付けは文字・行・矩形レジスタに従ってセル内へ挿入し、表の行・列を作りません。`c`から挿入終了までは一つの変更グループです。表構造の変更、チェックボックス、書式設定にはObsidianの操作を使います。

表連携はObsidian内部APIに依存し、Obsidianの更新によって使えなくなる場合があります。互換性を確認できない環境では連携を停止して通知します。Sourceモードへ切り替えるとMarkdown原文全体を編集できます。設定で表連携を無効にすることもできます。

## 設定

| 設定                                                                                                                   | 既定値     |
| ---------------------------------------------------------------------------------------------------------------------- | ---------- |
| Lindvimera、日本語の単語・文操作、見出し・リスト移動、Markdownテキストオブジェクト、Surround、テーブル連携、モード表示 | すべて有効 |
| Markdownに合わせた行追加・行頭操作                                                                                     | 有効       |
| 日本語の分割モード                                                                                                     | `normal`   |
| 挿入モードの脱出キー                                                                                                   | `[]`       |
| 脱出キーの判定時間                                                                                                     | 200ms      |
| モード別キー割り当て                                                                                                   | `[]`       |
| Vimキーで折り畳みを操作                                                                                                | 有効       |
| 入力待ちのキー候補を表示                                                                                               | 有効       |
| カーソルの色                                                                                                           | 既定の配色 |

「カーソルの色」のカラーピッカーで、全モード共通の色を選べます。Source・Live Previewの本文とネイティブテーブルセルへ即時に反映し、再起動後も保持します。Normal・Visual・Replaceではブロック、Insertでは細いカーソルに適用し、非フォーカス時のブロックは同色の輪郭になります。「既定に戻す」で従来の配色へ戻せます。

キー割り当ては「割り当てを追加」から、モード・入力キー・実行キー列をフォームで指定します。「適用」でまとめて保存し、「取り消す」で未保存の変更を戻します。行ごとに削除でき、入力中に重複・循環・未対応操作の理由を表示します。

| モード       | 入力キー | 実行キー列 | 動作                           |
| ------------ | -------- | ---------- | ------------------------------ |
| Normal       | `H`      | `0`        | 行頭へ移動                     |
| Visual       | `L`      | `$`        | 行末まで選択                   |
| Operator待ち | `H`      | `0`        | operatorの対象を行頭までにする |
| Insert       | `<C-l>`  | `<Esc>`    | Normalへ戻る                   |

特殊キーには`<Esc>`や`<CR>`などのVim表記を使います。同じモード・同じ入力の重複や循環する割り当ては保存できません。既存のキー割り当てはそのままフォームへ読み込みます。入力文字を記録せず脱出するキー列には、通常マッピングではなく専用の脱出キー設定を使ってください。

`Esc`と`Ctrl-[`の取消規則は変更できません。対応外の操作を参照する割り当ては、設定内容を残して適用を停止し、理由を表示します。その割り当てを参照する定義も停止しますが、無関係な割り当ては引き続き使えます。マクロや`.`の再生中に対応外の命令に遭遇した場合は再生を止めて通知します。そこまでの編集はUndoで戻せます。

## 操作ガイドと入力待ちの候補

設定の「操作ガイドを開く」またはコマンドパレットの「Lindvimera: 操作ガイド」から、対応操作をキー・操作名・説明で検索できます。モードや分類でも絞り込め、使用例、ユーザー割り当て、機能設定や割り当てによって無効な操作の理由を確認できます。

検索欄と絞り込みは上部に残り、操作一覧の右端のスクロールバーで末尾まで移動できます。ホイールのほか、Tabで一覧へ移動して矢印キー・PageUp／PageDownも使えます。検索条件を変更すると一覧の先頭へ戻ります。

操作ガイドと入力候補の説明は、行追加・行頭操作の設定に合わせて切り替わります。

`g`や`z`、operatorなどの入力途中で500ms待つと、続けて使えるキーを表示します。表示は入力・フォーカス・選択を変更しません。Insert／Replace、IME変換中、検索・専用入力UI、マクロの記録・再生中には表示しません。「入力待ちのキー候補を表示」で無効にできます。

## データの扱い

通常動作では外部へ通信せず、ノート本文を送信しません。日本語解析用のWASMと辞書は配布物に同梱され、メモリ上で読み込みます。設定はVaultの`.obsidian/plugins/lindvimera/data.json`へ保存し、ノートの変更はObsidianの編集・保存機能を通じて反映します。
